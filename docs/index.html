Quick start

Three steps from an empty workspace to your first skill run.
No Databricks? Check out Databricks Free Edition.

  1. Clone the repo into Databricks

    Add the repo as a Git folder in your workspace, then open Genie Code Customizations and add the skills/ folder so Genie Code can find every skill.

    Set up the Git folder →

  2. Sync skills to Unity Gateway Optional

    To share skills across a team, register them with sync_skills_git2unity.py. Skip this if you're trying skills on your own.

    Read the sync guide →

  3. Run your first skill

    Pick a skill above and ask Genie Code to "demo the skill-name skill". See more examples here.

    Choose a skill →
